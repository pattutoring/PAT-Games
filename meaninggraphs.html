Meaning is not merely a label attached to an isolated word. It is a relational state: a position produced by context, opposition, similarity, transformation and the surrounding semantic field.

A RELATIONAL MODEL OF MEANING

Meaning Exists in Relation

A word does not carry meaning in isolation like an object carries weight. Its semantic identity emerges through the relations that distinguish it, connect it, oppose it and preserve it as context changes.

↔ Relations Precede Observers Meaning can be modeled through the structure of relations before asking who happens to observe them.
± Context Determines Charge The same lexical object can acquire different semantic polarity when placed inside a different context.
⟳ Identity Through Transformation To understand a thing is not only to know what it is now, but what remains invariant as it transforms.
✦ Symmetry Is Selected For Stable meaning emerges where relations can repeatedly reconstruct a coherent structure from changing conditions.
∂ Meaning Has Direction Semantic change can have magnitude, direction and rate — not merely a before and after.
◌ The Model Is Never the Whole Field Every system leaves something outside its current description: the semantic dark matter capable of redirecting the structure when context expands.

FROM OBJECTS TO RELATIONS

The Graph Is Not a Picture of the Word

Object + Context + Relation → Semantic State

Meaning Graphs treats the lexical object as one component of a larger relational event. The same object can occupy different semantic positions because the surrounding field changes.

What persists through those changes becomes especially important. The invariant is not necessarily a hidden dictionary definition underneath every use; it may instead be the relational structure capable of generating those uses.

In this sense, semantic space itself is lexical: words, relations and contexts do not merely occupy a pre-existing map. Their interactions help construct the field being mapped.

The goal is therefore not merely to ask “What does this mean?” It is to ask: “What relations make this meaning reconstructible?”
